# Support — StealthBridge TypeScript SDK

> **Stellar Testnet engineering only.** `@stealthbridge/sdk` validates Testnet protocol contracts and client envelopes; it does not custody funds or broadcast Mainnet transfers.

## Where to get help

- **Types, validation errors, or OpenAPI sync issues:** Search [stealthbridge-sdk issues](https://github.com/stealthbridge-labs/stealthbridge-sdk/issues) and review [docs/DEVELOPER-GUIDE.md](docs/DEVELOPER-GUIDE.md) and [docs/OPENAPI-COMPATIBILITY.md](docs/OPENAPI-COMPATIBILITY.md).
- **Protocol 30 StrKey (`G`/`M`/`C`/`W`) support:** See [docs/PROTOCOL-30-ADDRESS-FORMATS.md](docs/PROTOCOL-30-ADDRESS-FORMATS.md).

Include Node version, `@stealthbridge/sdk` version/commit, minimal TypeScript snippet, and `npm run verify` output. Never paste private keys, session cookies, or draft passphrases.

For security disclosures, follow [SECURITY.md](SECURITY.md) privately.
